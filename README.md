# 🧠 Data Analytics Quiz App

A Python-based interactive quiz application designed to test knowledge of **Python, MySQL, Excel, and Data Analytics** through multiple-choice questions.

The application provides a simple and user-friendly graphical interface where users can answer questions, track their scores, and receive performance feedback.

## 🚀 Features

- 🐍 Python-related questions
- 🗄️ MySQL-related questions
- 📊 Excel-related questions
- 📈 Data Analytics-related questions
- 🎲 Randomized question order
- 🔘 Multiple-choice answers
- ➡️ Next Question functionality
- 🧮 Automatic score calculation
- 📊 Percentage calculation
- 🏆 Performance feedback
- ❌ Exit confirmation
- 💻 Simple and interactive GUI

## 🛠️ Technologies Used

- **Python**
- **Tkinter**
- **Random Module**
- **Messagebox**

## 📚 Quiz Categories

The quiz contains questions from four major areas:

| Category | Topics |
|---|---|
| Python | Variables, loops, functions, data types, libraries |
| MySQL | SQL queries, databases, commands, joins |
| Excel | Functions, formulas, Pivot Tables, data analysis |
| Data Analytics | Data cleaning, visualization, analysis, insights |

🎯 Purpose

This project was created as a practical Python project to improve knowledge of:

- Python programming
- GUI development
- Conditional statements
- Lists and dictionaries
- Functions
- Randomization
- Score calculation
- User interaction

It also provides a simple way to practice fundamental concepts related to MySQL, Excel, and Data Analytics.
